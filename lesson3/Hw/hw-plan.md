# ДЗ Урок 3 — план

## Задача 1 — Новые теги

1. Создать класс `P` (параграф)
   - Родитель: `PairTag`
   - Допустимые атрибуты: `class`, `id`

2. Создать класс `Ul` (ненумерованный список)
   - Родитель: `PairTag`
   - Допустимые атрибуты: `class`, `id`

3. Создать класс `Li` (элемент списка)
   - Родитель: `PairTag`
   - Допустимые атрибуты: `class`

4. Зарегистрировать все три тега в `index.php` и проверить, что рендерятся

## Задача 2 — Валидация дочерних элементов

5. Добавить в `PairTag` механизм ограничения допустимых дочерних тегов
   - Изменить файл: `SafetyHTML/PairTag.php`
   - По умолчанию — ограничений нет (текущее поведение сохраняется)
   - Если ребёнок не разрешён — `isValid()` возвращает `false` и вызывает `report()`

6. Настроить `Ul` так, чтобы он принимал только `Li` в качестве детей
   - Изменить файл: `CustomTags/Ul.php`

7. Написать два теста в `index.php`:
   - `Ul` → дети `Li` → `isValid()` = `true`, HTML выводится
   - `Ul` → ребёнок `Div` → `isValid()` = `false`, HTML не выводится, `report()` показывает ошибку
