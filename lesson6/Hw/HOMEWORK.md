# Домашнее задание к уроку №5 — Трейты

## Задача: Трейт Singleton

### Контекст

В исходниках урока (папка `1-hw`) реализован паттерн Singleton для класса `DB` и класса `Model`.
Посмотрите на `Core/DB.php` и `Core/Model.php` — в каждом из них одни и те же строки:

```php
protected static ?self $instance = null;

public static function getInstance(): self
{
    if (self::$instance === null) {
        self::$instance = new self();
    }
    return self::$instance;
}

protected function __construct() { ... }
```

Это **копипаста**. Если нужно добавить Singleton ещё в десяток классов — придётся копировать эти строки повсюду.

---

### Основное задание

Создайте трейт `Singleton` (например, в `Traits/Singleton.php`), который инкапсулирует в себе всю логику паттерна:

- статическое свойство `$instance`
- статический метод `getInstance()`, возвращающий единственный экземпляр класса
- `protected`-конструктор, закрывающий прямое создание объектов через `new`

После этого любой класс, которому нужна функциональность Singleton, должен просто написать:

```php
class DB
{
    use Singleton;
    // ...
}
```

**Требования:**

1. `DB::getInstance()` должен всегда возвращать один и тот же объект.
2. Прямой вызов `new DB()` должен быть недоступен извне класса.
3. Трейт не должен содержать логику конкретных классов — только механику Singleton.
4. Рефакторинг `Core/DB.php` и `Core/Model.php` с использованием нового трейта должен не сломать их работу.

---

### Задание со звёздочкой

Подумайте (и проверьте на практике): **что произойдёт с трейтом `Singleton`, если у класса появятся наследники?**

Например:

```php
class BaseModel
{
    use Singleton;
}

class UserModel extends BaseModel
{
    // ...
}

class PostModel extends BaseModel
{
    // ...
}
```

- `UserModel::getInstance()` и `PostModel::getInstance()` — это один объект или разные?
- Почему так происходит? Где именно в коде трейта кроется проблема?
- Как это исправить, чтобы каждый наследник имел **свой** независимый экземпляр?

**Подсказка:** обратите внимание на разницу между `self::` и `static::` в PHP.
